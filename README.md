I’ve completed TaskFlow a clean, modern task & project management app inspired by Monday.com/Jira.

Key features:
• Dark/light theme with bright yellow branding
• Dashboard: stats cards + task distribution pie chart
• Kanban board with drag & drop status change
• Create/edit projects & tasks with modals
• Comments on tasks
• Real-time search, filtering & sorting
• Export projects/tasks to CSV
• Responsive design & smooth UI interactions

Tech: React + Vite + Tailwind, Node/Express/MongoDB, JWT auth.
